# 应用时区

应用默认使用 `Asia/Shanghai`（北京时间）。管理员可在「设置 → 通用 → 应用时区」中手工输入有效的 IANA 时区名称，例如 `America/New_York`、`Europe/London` 或 `UTC`，然后点击「保存设置」。普通用户可查看当前全局时区。

时区保存在 `config/app-config.json` 的 `timeZone` 字段；旧配置未包含该字段时自动使用 `Asia/Shanghai`。保存后当前页面立即使用新时区，其他已经打开的客户端刷新页面后生效。

试卷创建时间、自动标题中的时间、错题列表、练习历史、管理页面日期、导出文件名、按日/月统计、考试日期录入和年级学期计算均使用应用时区。统计使用该时区的日历边界，兼容夏令时的 23 小时日与 25 小时日。

数据库及 API 中带 `Z` 的 ISO 时间表示绝对时刻，显示时再按应用时区转换。修改时区不平移数据库中的时间。已经保存的试卷标题属于文字内容，标题中原有的时间不会自动改写；新生成的默认标题使用创建时配置的应用时区。
