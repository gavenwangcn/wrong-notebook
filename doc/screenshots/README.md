# README 使用截图

这些图片于 2026-10-22 在本地运行当前版本，以浅色模式采集。图片仅做内容裁剪和无损 PNG 保存。

- 根目录供 `README.md` 使用：基于已有题目、动画讲解、试卷与练习记录的数据副本，用户名替换为「学生」，题目和统计数据保持原文。
- `en/` 供 `README.en.md` 使用：在独立演示数据库中准备英文题干、答案、解析、知识点、动画文字、试卷标题和变式题，再从实际运行的英文界面重新截图。`Student` 为演示用户，12 道题、42 条作答记录和掌握估计均为演示数据，不代表真实学生的学习成效。

英文内容素材保存在 [`en/demo-questions.json`](en/demo-questions.json)，六边形染色讲解使用 [`en/hexagon-coloring.svg`](en/hexagon-coloring.svg)。这些是截图内容素材，不是账户备份。英文标签仅用于本组演示，应用自带的知识点库仍遵循 README 中说明的中国 K-12 课程体系。

应用图标复用仓库中的 [`public/icons/icon.png`](../../public/icons/icon.png)。截图不包含实例访问地址或登录凭据。

| 文件 | 展示内容 |
| --- | --- |
| `notebook.png` | 错题卡片、知识点、难度与筛选入口 |
| `upload.png` | 拍照上传、文字录入与剪贴板粘贴 |
| `preferences.png` | 导入确认、讲解偏好与判重阈值 |
| `question-detail.png` | 题干、星级、知识点与试题信息 |
| `svg-animation.png` | 六边形染色题的动画讲解，英文版包含英文图示文字和计数表 |
| `mastery-history.png` | 变式题、作答历史与掌握概率 |
| `exam.png` | 已生成试卷、来源 ID 与作答结果 |
| `exam-print.png` | 试卷打印预览与导出入口 |
| `knowledge-tags.png` | 按学科、年级和章节展开的标签库 |
| `error-stats.png` | 错题数量、掌握率、科目分布与趋势 |
| `practice-stats.png` | 练习次数、正确率与趋势 |

更新图片时保留对应文件名，使用浅色模式，等待页面、图表及过渡动画完成后截图，裁切时保留完整的展示区域。英文截图须同时使用英文界面和英文内容；逐项检查题干、答案、解析、知识点、动画内嵌文字、试卷标题及变式题，不能只切换界面语言。核对截图与 README 说明一致，并在提交前检查用户名、邮箱、凭据和内部地址是否入镜。

涉及两种语言的功能变化应同步更新中英文两套截图；仅修正某种语言的内容时更新对应素材即可。官网 `../wrong-notebook-github-pages/assets/images/en/` 的六张 WebP 及英文分享图应与这里的英文 PNG 同步更新。
