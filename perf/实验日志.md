# 错题列表实验日志

## 假设

列表卡片不使用原图、解答和动画。使用 Prisma `select` 限制读取字段，并把完整标签缩为名称，可以同时减少数据库返回数据、JSON 序列化和响应大小。预计默认列表字节数减少 95% 以上，真实数据的查询加序列化 p75 至少降低 50%。

## 护栏

修改前的 784 项单元测试与 404 项集成测试通过。随后增加真实 SQLite 回归：52 题，每题含 128 KiB 原图和中英文各 64 KiB 动画；验证卡片、复习状态、分页、用户隔离、打印和认证，并将 18 题默认响应限制为 12 KiB。新增的大字段与打印测试在旧实现上先失败，字段投影修改后通过。

## 改动和结果

默认列表仅查询卡片字段；打印通过 `view=print` 额外查询原图、答案、解析、静态配图和打印元数据。前端分别使用摘要类型和打印类型，防止把列表数据误当成完整详情。

在运行容器中对同一份真实数据按旧查询、新查询交替各运行 10 次，包含相同的计数、分页、复习状态计算和 JSON 序列化：字节数从 1,212,462 降到 10,578；p75 从 155.68 ms 降到 21.17 ms。该测量不含认证与 HTTP 传输。

两个隔离的开发服务共享同一份 52 题合成数据，认证、页面参数和卡片内容相同，预热后交替各读取 10 次完整 HTTP 响应并解析 JSON。不限速 p75 从 28.60 ms 降到 16.83 ms；限制下载为 500,000 B/s 时从 2,402.04 ms 降到 29.21 ms。卡片内容与分页逐次比较一致。

保留此修改。没有增加数据库索引、缓存或数据库迁移：本次瓶颈来自读取和传输列表不使用的大字段。没有改动生产持久数据或切换运行版本。
