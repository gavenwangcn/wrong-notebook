# 错题列表接口性能简报

- 范围：`GET /api/error-items/list`，默认每页 18 题。
- 可用终点：响应 JSON 完整下载并解析，包含当前页全部卡片、复习状态和分页信息。
- 目标：同一数据集交替测量优化前后至少各 10 次，完整响应 p75 降低至少 50%。
- 保持行为：筛选、用户隔离、排序、分页、卡片内容和打印原图、题干、答案、解析均保持可用。
- 确定性指标：默认列表响应字节数；大图片和动画不得影响列表响应体积。
- 验证：现有单元与集成测试、真实 SQLite 的大字段与打印回归测试，以及相同机器上的配对 API 测量。
- 测量边界：服务端及本机接口测试，单独记录传输限速场景；私有服务没有 CrUX 数据，不将实验室结果当作真实用户指标。
- 上线：本地完成代码、测试和报告后确认；沿用现有部署与回滚流程。
- 数据约束：不修改已有题目、图片、账号或数据库结构；临时脚本、原始测量和日志保存在系统临时目录，不提交真实题目或服务器配置。
