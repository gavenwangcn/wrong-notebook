# Bundled Geist fonts

Source: https://registry.npmjs.org/geist/-/geist-1.4.2.tgz

Both variable WOFF2 files come from `geist` 1.4.2. The npm SHA-512 archive integrity was verified before extraction. See `LICENSE-geist.txt` for the SIL Open Font License.

Bundling the existing font families makes production builds independent of Google Fonts network access.
